# EShopSet SEO keyword research

Research date: 2026-10-02. Sources: EShopSet published use-case primary keywords (`eshopset.com` content), competitive Shopify App Store listings (SEO Metriks, FlyRank, Visibly AI, StoreSEO, BulkEdit/Sheets sync, CWS/Genseo content apps), and Shopify’s own AEO/GEO guidance.

## Competitive SERP themes (what merchants search)

1. **All-in-one vs point apps** — merchants compare stacks of SEO + AI visibility + Sheets sync + linking + content tools; bundle pricing messaging wins on “from $49/store/mo”.
2. **Rank tracking for storefronts** — not App Store ASO; emphasize domain trust, organic keywords, competitors, daily sync.
3. **AI search citations** — ChatGPT / Gemini / Perplexity / AI Overviews brand mentions; AEO/GEO vocabulary is rising (Shopify blog coverage).
4. **Sheets → Shopify** — import, scheduled sync, SKU/handle match, preview before apply vs blind CSV.
5. **Internal linking automation** — orphans, underlinked hubs, blog→product links.
6. **Evidence-backed AI content** — opportunities from catalogue + GSC before spending draft credits.
7. **MCP / Sidekick** — operate apps from the merchant’s preferred agent, not only Admin UI.

## Mapping rules used in this repo

- One Markdown page per **published** website use case (41 pages).
- H1 stays outcome-focused; **primary keyword** called out in a lead block and first paragraph.
- Illustrations copied from the live site product screenshots (same PNGs).
- Canonical website URL linked on every page so GitHub + site reinforce each other.
- Category README hubs target the cluster head terms.
