**multi-store Shopify SEO baseline** means each Shopify store keeps its own plan, app enables, and usage limits—not a shared multi-store control center. This use case shows how in-house teams, agencies, and freelancers run portfolio SEO baselines per store store by store with EShopSet.

_In-house teams: set SEO Performance Monitor baselines on every Shopify store in the portfolio—domain trust, rankings, and competitors—with a separate plan per store._

## Outcomes

- One SEO Performance Monitor install and plan limits per Shopify store
- Capture domain trust, organic traffic, and keyword rankings as a portfolio baseline
- Compare stores with the same ritual—no Agency Tools required

## Why baseline every store

Portfolio averages hide which brand is slipping. A per-store baseline makes ownership clear: which domain lost trust, which keywords dropped, which competitor gained share—before merchandising or content teams guess.

## How it works in EShopSet

Connect each Shopify store, enable SEO Performance Monitor, set locale/countries/keyword caps in Settings, and pin Domain Trust, Organic Traffic, and Backlinks on Overview. Limits follow that store’s [plan](https://eshopset.com/pricing/). Repeat the same Settings checklist for store two, three, and so on.

## Example: three-brand apparel group

An in-house SEO lead rolled Growth on Brand A and Starter on Brands B & C. Week-one baselines showed Brand B’s referring domains flat while Brand A gained 18 ranked keywords—so content capacity shifted to Brand B without waiting for a shared “portfolio report.”

## Playbook

1. List every live Shopify store and its EShopSet plan.
2. Enable SEO Performance Monitor on store 1; complete Settings.
3. Record Overview KPIs in a shared sheet (store | date | trust | traffic | top movers).
4. Repeat for each remaining store.
5. Weekly: scan each Overview; escalate to Logs only when sync fails.

## What to measure

- % of stores with a completed baseline within 7 days of enable
- Stores with ranking drops >5 positions on priority keywords
- Sync freshness (<24h) per store Overview

## Proof points

- **Per store** — Plan + SEO app install
- **Daily** — Sync cadence
- **25–100** — Keywords by plan
