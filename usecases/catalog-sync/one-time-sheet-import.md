## Why one-time before scheduled

Scheduled syncs amplify mapping mistakes. A one-time import lets ops validate handles, variants, and price columns on a real catalog slice—often 200–800 SKUs—before hourly jobs touch production.

## How it works in EShopSet

In [Data Sync](https://eshopset.com/apps/data-sync/), connect the Google Sheet, map columns, run manual preview, review creates/updates/archives, then apply. Check Logs for partial failures. Stay within plan row limits.

## Example: supplier price book

A reseller received a 640-row supplier sheet with new prices. On Growth they mapped SKU, price, and inventory only, previewed 640 updates / 0 creates / 0 archives, applied in one run, and confirmed Logs showed 640/640 success—avoiding a weekend of Admin CSV uploads.

## Playbook

1. Copy the sheet; freeze a working tab for import.
2. Map required Shopify fields; leave merchandising columns unmapped if needed.
3. Preview; resolve unexpected archives/creates.
4. Apply during a low-traffic window.
5. Spot-check 5 PDPs in Shopify Admin; review Logs.

## What to measure

- Preview counts vs applied counts
- Log error rate (target <1% on clean sheets)
- Time saved vs last manual CSV upload

## Proof points

- **1k / 5k** — Row limits by plan
- **Preview first** — Safety gate
- **Minutes** — Typical apply for mid catalogs
